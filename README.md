# ex-nihilo-OS
Простая самописная unix-like ОС для x86 (32 бита, защищённый режим).

## Что уже есть

* **boot.asm** — загрузочный сектор: включает A20, определяет геометрию диска
  через `int 0x13/ah=0x08`, читает 64 сектора ядра в `0x10000` по LBA→CHS
  (с повторами и сбросом диска при ошибке), затем переходит в защищённый режим.
* **kernel.asm** — 32-битная точка входа: сегменты, стек `0x90000`, вызов `kmain`.
* **kernel.c** — вывод в текстовый видеобуфер VGA и демонстрация работы PMM.
* **hal/pmm.asm** — менеджер физических страниц (bitmap, 1024 страницы = 4 МиБ)
  под спинлоком: `pmm_init` / `pmm_alloc` / `pmm_free` / `pmm_free_pages`.
* **hal/spinlock.asm** — спинлок на `xchg` + варианты с сохранением прерываний.
* **tests/** — host-тест PMM: линкуется с настоящим `hal/pmm.asm` и прогоняется
  как обычная 32-битная программа.

## Сборка и запуск

Нужны `nasm`, `gcc` с поддержкой `-m32`, `ld`; для запуска — `qemu-system-i386`.

```sh
make            # build/os.img — образ дискеты 1.44 МБ (boot + kernel)
make run        # запуск в QEMU
make test       # тесты PMM
```

## Карта памяти

| Диапазон              | Что это                                         |
|-----------------------|-------------------------------------------------|
| `0x000000`–`kernel_end` | загрузчик, код и данные ядра, BDA              |
| `kernel_end`–`0x07FFFF` | свободные страницы (выдаёт `pmm_alloc`)       |
| `0x080000`–`0x08FFFF`   | стек ядра (растёт вниз от `0x90000`)          |
| `0x09FC00`–`0x09FFFF`   | EBDA                                          |
| `0x0A0000`–`0x0BFFFF`   | видеопамять VGA                               |
| `0x0F0000`–`0x0FFFFF`   | BIOS ROM                                      |

Всё от `0x80000` до `0xFFFFF` PMM считает занятым: освобождать и выдавать
эти страницы нельзя.

## Интересная информация
ex nihilo переводится как "из ничего".
