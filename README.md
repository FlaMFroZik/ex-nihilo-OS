# ex-nihilo-OS
Простая самописная unix-like ОС для x86 (32 бита, защищённый режим).

## Что уже есть

* **boot.asm** — загрузочный сектор: включает A20, определяет геометрию диска
  через `int 0x13/ah=0x08`, **опрашивает карту памяти BIOS
  (`INT 15h`, `AX=E820h`)**, читает 64 сектора ядра в `0x10000` по LBA→CHS
  (с повторами и сбросом диска при ошибке), затем переходит в защищённый режим.
* **kernel.asm** — 32-битная точка входа: сегменты, стек `0x90000`, вызов `kmain`.
* **kernel.c** — вывод в текстовый видеобуфер VGA: карта E820, объём ОЗУ,
  демонстрация `pmm_alloc` / `pmm_free`.
* **hal/pmm.asm** — менеджер физических страниц: bitmap **на всю доступную ОЗУ**
  (1 МиБ bitmap = 4 ГиБ памяти), построенный по карте E820, под спинлоком.
* **hal/spinlock.asm** — спинлок на `xchg` + варианты с сохранением прерываний.
* **tests/** — host-тест PMM: линкуется с настоящим `hal/pmm.asm` и прогоняется
  как обычная 32-битная программа.

## Карта памяти: INT 15h / AX=E820h

`INT 15h` с `AX=E820h` — прерывание **BIOS**, поэтому оно работает только в
реальном режиме. Ядро (`hal/pmm.asm`) уже выполняется в защищённом режиме, где
`int 0x15` уйдёт в IDT (которой у ядра нет) и приведёт к исключению. Поэтому
цепочка такая:

```
boot.asm (16 бит, реальный режим)
    INT 15h, AX=E820h  ──цикл по EBX──►  карта в 0x0600/0x0608
                                              │
                                              ▼  (0x0600: count, 0x0608: записи по 24 Б)
hal/pmm.asm (32 бита, защищённый режим)
    pmm_init() ── разбирает E820 ──► bitmap + page_limit
```

Формат записи (ACPI 3.0, 24 байта): `base` (qword), `length` (qword),
`type` (dword; `1` — доступна ОС), `acpi_ext` (dword).

Алгоритм `pmm_init`:

1. Весь bitmap помечается занятым (**fail closed**: пока карта не разобрана,
   память не выдаётся).
2. Для каждой записи `type == 1` диапазон `[base, base+length)` освобождается,
   `page_limit` расширяется до верхней границы памяти.
3. **Заново** помечаются занятыми все области `type != 1`. Порядок важен:
   записи E820 бывают пересекающимися (базовая память кончается на `0x9FC00`,
   EBDA начинается там же — они делят страницу `0x9F000`). При обратном
   порядке эта страница оставалась «свободной».
4. Резервируются: всё до `kernel_end` (загрузчик, код, данные ядра), стек
   `0x80000..0x90000`, страница 0.
5. Если карты нет — используется нижняя граница памяти от BIOS (int 12h),
   и EBDA / VGA / BIOS ROM резервируются вручную.

`pmm_free()` проверяет, что страница **целиком** лежит в области `type == 1` и
не пересекается ни с одной областью `type != 1`. Без этой проверки можно было
«освободить» видеопамять, BIOS ROM или MMIO-дыру: они помечены тем же битом
«занято», что и выданные аллокатором страницы.

Области с `type != 1` (VGA, BIOS ROM, MMIO, дыры) остаются занятыми, поэтому
`pmm_alloc` их никогда не выдаёт — это проверяется тестами.

## Производительность аллокатора

`pmm_alloc` хранит подсказку (`alloc_hint`) о том, где закончился прошлый
поиск, поэтому N выделений подряд стоят O(N), а не O(N²). Подсказка
откатывается назад в `pmm_free`, поэтому освобождённые страницы переиспользуются.
Полный обход миллиона страниц (4 ГиБ) занимает миллисекунды.

`pmm_free_pages()` возвращает инкрементально поддерживаемый счётчик, а не
пересчитывает bitmap.

## Сборка и запуск

Нужны `nasm`, `gcc` с поддержкой `-m32`, `ld`; для запуска — `qemu-system-i386`.

```sh
make            # build/os.img — образ дискеты 1.44 МБ (boot + kernel)
make run        # запуск в QEMU
make test       # тесты PMM (в т.ч. разбор E820 и «дыр» в памяти)
```

## API PMM

| Функция | Что делает |
|---|---|
| `pmm_init()` | строит bitmap по карте E820 |
| `pmm_alloc()` | выдаёт физическую страницу (4 КиБ) или `NULL` |
| `pmm_free(addr)` | возвращает страницу (плохие адреса игнорируются) |
| `pmm_free_pages()` | свободных страниц |
| `pmm_total_pages()` | страниц в модели памяти |
| `pmm_usable_bytes()` | объём доступной ОЗУ (насыщается в `0xFFFFFFFF`) |
| `pmm_e820_entries()` | записей в карте E820 |
| `pmm_e820_usable()` | из них доступных (`type == 1`) |
| `pmm_e820_entry(i, &e)` | скопировать запись в структуру `e820_entry_t` |

## Интересная информация
ex nihilo переводится как "из ничего".
